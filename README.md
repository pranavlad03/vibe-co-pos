# VIBE CO. POS
Mobile-first café ordering and billing front end for GitHub Pages, connected to Google Apps Script and Google Sheets.

## Files
- `index.html` — interface
- `styles.css` — responsive styles
- `app.js` — menu/order API calls

## Setup
The Apps Script URL is configured in `app.js`. Ensure the backend endpoints `getMenu`, `getOrders`, and `createOrder` are available. Before using for real payments, review and test the Apps Script backend thoroughly.
